## Purpose

Map what already exists so VeriGlow-ai solves an unmet need instead of rebuilding an existing tool.

## Competitor Categories to Investigate

| Category | Description |
|---|---|
| **Direct** | Consumer tools that check beauty product authenticity |
| **Brand-led** | Authentication features from brands themselves (e.g. scannable codes, holograms) |
| **Marketplace-led** | Authenticity programmes or seller badges run by marketplaces |
| **Adjacent** | Batch-code decoders, ingredient-safety apps, review analysers |
| **Behavioural** | What buyers do instead (official stores, offline purchase) |
